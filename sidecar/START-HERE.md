# UCM-AMCAS Agentic Adaptation Sidecar

Place this extracted folder beside an extracted Mosaic UCM v0.1 core. The
sidecar does not duplicate or replace UCM. It verifies the core's exact system
and capability registries, then forwards a bounded set of integration commands
to that core.

For humans on Windows, run `RUN-UCM-AMCAS-ADAPT.cmd` and select the UCM folder.
For agents:

```text
python UCM-AMCAS-ADAPT.py --ucm-root PATH sidecar-orient
python UCM-AMCAS-ADAPT.py --ucm-root PATH verify-core
python UCM-AMCAS-ADAPT.py --ucm-root PATH ucm orient
python UCM-AMCAS-ADAPT.py --ucm-root PATH ucm capabilities
```

Then read `skill/ucm-amcas-integration/SKILL.md`. Bind exact source bytes,
inventory native control planes, compile AMCAS, use shadow correspondence,
return a THR-separated Stage I1 bundle, and import explicit bilateral Stage I2
declarations through the portfolio. Provider invitations are not consumer
consent. A clean preflight advances only to a correspondence court.

Progress written to stderr is nonsemantic. The journal and bound G1/G2/G3
receipts are evidence. This package remains INFORMATION_ONLY with authority
effect NONE, real A5 false, and G0 closed.
