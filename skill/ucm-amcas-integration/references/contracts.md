# Contract and report checks

The integration kit contains an AMCAS contract and its compiled IR. Verify both
before work. The contract separates CM1 membership, CM2 ordering, exact
configuration, implementation bytes, execution evidence, and revision.

Every report must bind the exact contract, IR, journal head, and application
source root. A `PASS` disposition that requires evidence must name at least one
evidence root. Every operation is terminal only after G1 Sentinel, G2 Witness,
and G3 Diagnostic events occur in order. The canonical journal archive is the
portable record; console text and the progress stream are observations only.

Do not reinterpret source-bound candidate terms as canonical law. Record an
unresolved semantic jurisdiction as unresolved.
