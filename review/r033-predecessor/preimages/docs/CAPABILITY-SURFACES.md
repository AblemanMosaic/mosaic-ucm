`ucm.invoke` accepts a compatibility `mosaic.ucm.request.v0.1` envelope, which is fixed to the AUTHORING profile, or a `mosaic.ucm.request.v0.2` envelope containing an explicit `profile_selection`. The dispatcher validates that selection against the capability registry and refuses a surface outside the selected profile. `ucm operational-invoke` always selects OPERATIONAL. Profiles attenuate surfaces and grant no authority. The machine registry supplies exact request/result schema names.

Predecessor routes are deliberately absent from this default registry. Use `python tools/ucm.py legacy-capabilities` and the explicit `COMPATIBILITY` profile only for migration or exact historical replay.
