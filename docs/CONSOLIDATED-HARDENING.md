# Consolidated hardening campaign

The successor separates feature completion from adversarial hardening. A MED or HIGH
happy-path defect blocks the boundary. LOW hardening findings are accumulated and
repaired as one batch so review cycles do not repeatedly rediscover adjacent cases.

Builder testing is limited to positive, static, and ordinary refusal checks. The user
runs the sealed disposable adversarial kit. Independent review occurs only after a
meaningful batch and remains distinct from builder and operator evidence.

The machine-readable campaign enumerates happy-path gates, hardening families,
portability legs, and verdict rules in
[`program/CONSOLIDATED-HARDENING-CAMPAIGN.json`](../program/CONSOLIDATED-HARDENING-CAMPAIGN.json).
