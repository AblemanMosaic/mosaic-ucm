# Authority ceiling

UCM v0.1 has the following global ceiling:

```json
{
  "standing": "INFORMATION_ONLY",
  "authority_effect": "NONE",
  "real_a5": false,
  "g0": "CLOSED",
  "identities": "UNBOUND",
  "deployment": "NOT_AUTHORIZED",
  "network": "NOT_AUTHORIZED"
}
```

Local tests, examples, proof certificates, qualification receipts, and independent recommendations cannot broaden this ceiling. A later release or deployment requires an explicit authority artifact outside this repository and verification against the intended constitution, identity, target, and custody state.
