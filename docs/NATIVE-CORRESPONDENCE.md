# Native/UCM correspondence

UCM enters an established application in shadow mode. The application retains
its semantic authority and effect executors. Each correspondence case binds an
input root and records native and UCM decisions and result roots. A court passes
only when both are equal for every case. Divergence produces a hold.

Control planes are RETAIN, ADAPT, or REPLACE_AFTER_EQUIVALENCE. The last choice
requires rooted equivalence evidence. This prevents integration from creating a
second repair, test, deployment, or effect authority beside the native plane.
