# UCM-AMCAS two-track roadmap

## Track A — portable integration pipeline

The pipeline is independently releasable infrastructure. It orients an agent,
binds exact subjects, compiles AMCAS, maintains MosaicID and DKN boundaries,
records G1/G2/G3 receipts, builds Stage I1 returns, journals bilateral Stage I2
declarations, runs correspondence courts, and exports canonical handoffs. Its
release does not depend on completion of the Mosaic application migration.

The v0.1 completion boundary is a deterministic standalone archive, a checked
installer, exact runtime and portfolio schemas, live nonsemantic progress,
sealed manual-review support, clean-host smoke tests, and one cache-free
qualification. It remains information-only and grants no operational effects.

## Track B — Mosaic ecosystem migration

The migration is a portfolio of exact subjects processed by a pinned pipeline
version. Its present checkpoint contains seven Stage I1 bundles, seven latest
Stage I2 declarations, thirteen bilateral edges, and an operator-reproduced
118-case correspondence court. That evidence permits Stage I3 shadow planning;
it does not authorize shadow execution, composition, deployment, or effects.

The next checkpoint is fixed-denominator Stage I3 shadow planning. Every plan
is exact-subject bound and must preserve native semantic/effect authority.
Planning completion does not authorize a shadow run. Later milestones are a
separately authorized shadow correspondence run, bounded pilots,
cross-application composition, MosaiCOS correspondence, Genesis bootstrap, and
ecosystem qualification. Feedback may inform later pipeline versions without
changing the frozen pipeline used for an existing portfolio event.

## Shared rule

Every portfolio record names the exact pipeline artifact that produced it.
Pipeline releases never claim application acceptance. Application migration
never mutates a frozen pipeline release. Both tracks preserve
`INFORMATION_ONLY`, authority effect `NONE`, real A5 false, and G0 closed until
a separately verified authority transition says otherwise.
