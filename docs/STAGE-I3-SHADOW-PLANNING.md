# Stage I3 shadow planning

Stage I3 converts the exact Stage I1 subject, latest Stage I2 declaration, and
adversarial correspondence evidence into an application-authored comparison
plan. It is a planning boundary, not shadow execution.

An instruction binds the frozen pipeline release, predecessor portfolio,
portfolio status, composition preflight, correspondence court, and the exact
Stage I1 and Stage I2 artifacts. It separates CM1 requirements from CM2
priorities.

A returned plan names native routes, UCM projections, effect classes, retained
control planes, rooted inputs, expected decisions, evidence requirements,
relation dispositions, holds, and exclusions. The validator requires every
matched Stage I2 relation to receive a disposition and preserves inherited
Stage I1 holds.

The portfolio imports each plan through G1 Sentinel, G2 Witness, and G3
Diagnostic receipts. Completion means all seven plans are available for
review. It does not authorize execution, composition, deployment, capability
grants, or replacement of a native control plane.

```text
ucm portfolio-issue-stage3-instructions WORKSPACE PREDECESSOR.zip OUT ...
ucm stage3-validate-plan INSTRUCTION.json PLAN.json
ucm portfolio-import-stage3-plan WORKSPACE PLAN.json --event-id-prefix ID
```

Standing remains `INFORMATION_ONLY`, authority effect `NONE`, real A5 false,
and G0 closed.
